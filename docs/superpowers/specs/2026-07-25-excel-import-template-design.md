# 설계: 채우기 쉬운 3시트 가져오기 양식 + 파서 연결

## 배경 — 왜 필요한가

앱에는 이미 엑셀 가져오기가 있다: `src/excel.ts`의 `parseWorkbook()`가 일자·시간·일정(구분)·
세부(장소)·주소·비고 컬럼을 유연하게 읽어 밴드(조식/오전/중식/오후/석식/저녁)로 매핑하고,
`src/components/ScheduleImport.tsx` 모달이 미리보기 후 일정(slot)·장소(place)를 만든다. "템플릿"
다운로드 버튼(`downloadTemplate()`)도 있다.

그러나 현재 템플릿은 예시 한 세트짜리 단일 시트라, 교사가 처음부터 표를 구성해야 한다. 목표는
**"칸(장소명)만 채우면 되는 잘 짜인 양식"** — 하루 골격(오전활동2/점심/오후활동2/저녁/이후·숙소)이
미리 박힌 시트를 여행 길이별(1박2일·2박3일·3박4일)로 제공하고, 그 양식이 파서에 매끄럽게 물려
일정에 자동 반영되게 한다.

## 목표

- 교사는 **세부(장소명)** 칸만 채우면 일정이 완성된다(시간·구분은 미리 채움).
- 여행 길이별 3개 시트(`1박2일`/`2박3일`/`3박4일`)를 하나의 워크북으로 제공.
- 채운 데까지가 여행 — 빈 장소 행은 무시(빈칸=종료).
- 기존 가져오기 UI/흐름(`ScheduleImport` → `apply()`) 그대로 재사용.

## 범위 밖

- 주소 → 좌표 자동 지오코딩(현재 import는 좌표를 안 만든다. 지도 표시는 기존 방식 유지 — 후속).
- 조식(아침) 행: 사용자 요청대로 "매일 동일 골격"이라 조식 행은 넣지 않음(필요시 교사가 행 추가).
- 시트별로 다른 골격(도착일/출발일 구분) — 매일 동일 골격으로 확정됨.

## 결정된 설계 (사용자 확정)

- 매일 **동일 골격**. 교사가 입력한 데까지가 여행이고, **빈 장소 행은 종료/무시**.
- 시간 입력은 **옵션**(미리 채워두되 지우거나 바꿔도 됨).
- 밴드는 '일정' 라벨로 자동 판정(시간 없어도 동작).

## 아키텍처

### A. 양식(엑셀) — 3개 시트, 컬럼 `일자·시간·일정·세부·주소·비고`

각 시트 = **하루 7행 골격 × 일수**. 시트명과 일수: `1박2일`→2일, `2박3일`→3일, `3박4일`→4일.

**하루 골격(7행) — 일자·시간·일정 미리 채움:**

| 시간 | 일정 | → 밴드 |
|---|---|---|
| 09:00 | 오전활동① | 오전 |
| 11:00 | 오전활동② | 오전 |
| 13:00 | 점심 | 중식 |
| 14:00 | 오후활동① | 오후 |
| 16:00 | 오후활동② | 오후 |
| 19:00 | 저녁식사 | 석식 |
| 20:30 | 숙소/야간 | 저녁 |

- `일자`는 각 날의 **첫 행에만** '1일차'/'2일차'… 표기(나머지는 빈칸 — 파서가 아래로 이어받음).
- `세부·주소·비고`는 비워 둠(교사 입력). 워크북 첫 시트에 짧은 사용 안내 한 줄을 헤더 위에 둘 수 있다.

### B. 파서 연결 (`src/excel.ts` 변경 3가지)

1. **다중 시트 처리**: 현재 `wb.SheetNames[0]`만 읽음 → 모든 시트를 파싱해 **유효 행이 가장 많은
   시트**를 선택(교사가 자기 여행 길이 시트 하나만 채우므로 그 시트가 뽑힘). 동률이면 앞 시트 우선.
   `ParseResult.sheetName`은 선택된 시트명으로.
2. **빈 장소 행 건너뛰기**: "내용 있음" 판정을 **장소(place) 또는 활동(activity)이 있을 때**로 바꾼다.
   지금은 카테고리(일정 라벨)만 있어도 행을 만든다 → 템플릿의 미입력 골격 행이 빈 슬롯으로 들어오는
   문제. 카테고리(밴드 라벨)만 있는 행은 밴드 판정에만 쓰고 **슬롯은 만들지 않는다**.
3. **'숙소' 밴드 매핑**: `BAND_SYNONYMS`의 저녁(야간) 항목에 `숙소`, `야간활동`을 추가해 '숙소/야간'
   라벨이 저녁 밴드로 매핑되게 한다.

### C. 템플릿 생성 (`downloadTemplate()` 교체)

`downloadTemplate()`가 위 3시트 구조의 워크북(`여정_일정_템플릿.xlsx`)을 생성하도록 교체. 각 시트에
골격 행을 미리 채우고, `!cols`로 열 너비 지정. 첫 날 첫 행 정도에 예시 장소(예: '성산일출봉')를
넣어 채우는 법을 보여줄 수 있다(선택). `ScheduleImport`의 "템플릿" 버튼은 그대로 이 함수를 호출.

## 검증

- 순수 로직(`scripts/test-*.mjs`, vite `ssrLoadModule`): `parseWorkbook`가 (a) 3시트 중 채워진
  시트를 고르고, (b) 빈 장소 골격 행을 건너뛰고, (c) '숙소' 라벨을 저녁으로 매핑하는지. `xlsx`로
  in-memory 워크북을 만들어 검증(파일 불필요).
- 회귀: 기존 가져오기 e2e(`scripts/e2e-import.mjs`, yeosu 파일)로 실제 파일 파싱이 안 깨지는지.
- 브라우저 스모크(선택): ScheduleImport 모달에서 새 템플릿을 만들어 채워 적용 → 슬롯 반영 확인.
