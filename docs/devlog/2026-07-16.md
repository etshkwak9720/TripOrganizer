## perf: subset the icon font, cutting first load from 9.0MB to 1.7MB

`80a1b95`

The full Material Symbols face is 3.9MB of ~6,500 glyphs and the PWA
precached every byte; the app draws 67 of them. Subsetting has to prune the
ligature table first — the icon names are spelled out of latin letters, so
pyftsubset's glyph closure keeps every icon sharing those letters (--text and
--glyphs alone each got 3.9MB down to only 3.4MB), while dropping the letters
would stop the names resolving at all.

Which strings are icons is decided by the font rather than by matching prop
shapes: names arrive via <Icon name>, a wrapper's icon prop, table data, and
inline ternaries, and regexes over those shapes missed 13 icons and then 4
more, each rendering its name as literal text on screen. smoke-icons.mjs walks
every screen and fails on any icon box wider than it is tall, which is what
caught them.

The full face is kept out of public/ for regeneration via `npm run
icons:subset`, so it no longer ships.
